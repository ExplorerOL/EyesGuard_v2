# Журнал уроков

Формат записи:

```
## [RETRO-ГГГГММДД-XXX]
- Дата: ГГГГ-ММ-ДД
- Категория: skills | no-ops | тул-экономика | процесс | код
- Урок: «Когда X — делай Y» (кратко, без привязки к задаче)
- Решение: что сделано/изменено
- Статус: applied | proposed | rejected
- Повторы: n
```
