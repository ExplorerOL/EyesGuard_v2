# Приложение EyesGuard (домен)

EyesGuard — утилита для Windows, напоминающая о необходимости перерыва при
долгой работе за ПК: отсчитывает рабочий интервал, предупреждает о скором
перерыве, показывает окно перерыва и возвращает в рабочий режим.

Пользовательский интерфейс: иконка в трее (меню: Status / Settings / Exit) +
уведомления трея; главное окно скрыто. Подробности:

- [state-machine.md](state-machine.md) — шаги, переходы, длительности
- [settings.md](settings.md) — настройки и их валидация

Лицензия: GPL v3. Целевое окружение: Python 3.11, Windows 10. Сайт: https://eyesguard.ru
