# skills/

Скиллы opencode, специфичные для этого проекта. Каждый скилл — директория с
обязательным `SKILL.md` (frontmatter: name, description) и вспомогательными файлами.

Глобальные (личные) скиллы пользователя лежат вне репозитория и сюда не дублируются.
Добавляйте сюда только то, что пригодится любому агенту, работающему с EyesGuard_v2.
