Выполни задачу пользователя с использованием субагентов последовательно выполняя шаги.

1.  Уточни задау и сбери данные для выполнения. Обязательно определи, новые сущности и в каких файлах они будут храниться. Сам ничего не выясняй. Делегируй задачу субагенту с указанием использовать скилл .agents/skills/grill-with-docs для уточнения задач и документирования данных, создания критериев приемки задачи. 
DoD: все собранные данные и решения детально описаны и сохранены в соответствующих файлах в директории с файлом описанием задачи, в файле контекста CONTEXT.md - общий контекст задачи. 

2. Если нужно написать автотесты, то напиши тест-кейсы для них в отдельном файле test-cases.md. Делегируй задачу субагенту с указанием действовать как опытный QA инженер и испльзовать техники тест-дизайна. Перед записью в файл согласуй перечень тест-кейсов с пользователем.
Dod: В файле test-cases.md описаны тест-кейсы, если они трубуются по задаче.

3. Подготовь файл задания для ИИ агента, чтобы он смог быстро и эффективно выполнить задачу. Делегируй задачу субагенту с указанием использовать скилл .agents/skills/skill-create-ai-ready-task/ для подготовки задачисоздай файл ai-ready-task.md
DoD: в диретории с описанием задачи есть файл ai-ready-task.md в котором описана задача для ИИ агента, есть ссылки на ранее созданные файлы с детальным описанием и контекстом.

4. используй скилл subagent-driven-development для написания кода задачи
   Требование к имплементёру: сохранить скрипт проверки в <task-dir>/scripts/verify.py (сверка эталонов из CONTEXT.md с кодом, запрет-импорты, лимиты строк). Ревью-субагент запускает verify.py первым делом и прикладывает вывод в review-task-N-report.md.
Dod: выполнены критерии приемки задачи из шага 2; в директории задачи есть scripts/verify.py, его прогон приложен к отчёту ревью.

5. Финальное ревью: субагент проверяет DoD всех задач, затем обновляет граф знаний (memory_add_observations / memory_create_relations) и заметки .agents/memory/ по существенным изменениям (клиенты, фикстуры, CI).
Dod: граф и заметки отражают итоговое состояние задачи.
