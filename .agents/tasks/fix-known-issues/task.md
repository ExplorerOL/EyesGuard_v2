# Fix all known issues from known-issues.md

## Исходная постановка пользователя (2026-11-19)

> исправь все проблемы в проекте ранее найденные при ревью и описанные в файле
> .agents/memory/prj/known-issues.md
>
> один коммит - одна проблема. Отмечай статус каждой из них в этом же файле.
> работай на текущей ветке release/v2.3.1.
> перед изменениями сначала пиши тесты на уже работающую функциональность,
> затем вноси изменения и прогоняй тесты заново

## Процесс

- Порядок работ — по этапам из раздела «Рекомендуемый порядок улучшений» known-issues.md.
- Один коммит = одна проблема; статус проблемы отмечается в known-issues.md тем же коммитом.
- Перед правкой — тесты на текущее поведение, после правки — повторный прогон `uv run pytest -v`.
- Линт затронутых файлов: `uv run ruff check --fix --config=./linter_ruff.toml` + `ruff format`.
- GUI/трей/MCI/WinAPI — ручная проверка на Windows (недоступна агенту), фиксируется в статусах.
